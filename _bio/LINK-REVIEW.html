The 60 link positions resolve to 42 distinct URLs, so that is how many you actually have to open. A URL used in more than one entry is one decision; marking it here marks every entry that points at it. Hover also… to see where else it appears.

The rule the list lives by: if a URL 404s, the entry keeps its text and loses its link. An unlinked credential is fine; a dead link is not. Mark weak for a URL that resolves but should point somewhere better — a library homepage where a catalog record exists.

The loop: hit Open next unchecked, glance at the tab, then press 1 works, 2 gone, or 3 weak. Marking jumps the cursor forward, so it is open-look-key, open-look-key. Every row also has its own Open, and each section can throw its next five into tabs at once.

Keys: o or Enter opens, j/k move, 1/2/3 mark, 0 clears one. Marks save in this browser as you go, so you can stop and come back.
